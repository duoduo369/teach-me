# 中文写作指南

写教学文本时加载这份指南。教学文本的目标：**让读者看完一段就知道一件事，看完一篇就能用上一件。**

---

## 核心原则

**像个懂行的人在跟朋友解释一件事。** 知道一些事，有判断，偶尔岔开一句，还能接回来。不扮演老师，不扮演权威，不扮演"我来告诉你"。

两件事贯穿始终：

1. **材料** — 开口之前，手里有东西可说。没有材料就去找，找不到就缩短篇幅，不要用重复解释灌字数。
2. **推进** — 每段都带来新东西。上一段没说完的，这段接着说；说完了就翻篇，不回头重讲。

---

## 材料检查

动笔之前，确认手里有至少五件具体材料：一个事实、一个数据、一段代码、一个命令、一个场景、一个对比、一个反例——任选五种。

材料不够时：
- 去 RESOURCES.md 里找
- 去搜索
- 追问用户
- 缩小这篇的范围

不要用形容词和副词假装有材料。"非常重要""特别关键""格外注意"——这些不是材料，是占位符。

---

## 推进

每一段推进一步。判断推进的唯一标准：**删掉这段，读者会少知道什么？** 如果答案是什么也没少，就删掉。

推进的方式：
- 上一个事实 → 下一个事实
- 一个概念 → 它的具体例子
- 一个问题 → 一个解法
- 一个说法 → 一个反例
- 一个结论 → 一个边界条件

避免的推进：
- 换一种说法再说一遍
- "也就是说……""换句话说……""简单来说……"
- 把上一段扩写成三段的排比
- "那么问题来了……"（然后回答一个没人问的问题）

---

## 写完自查

每写完一段，检查以下条目。每条先给正面写法，再列要查的句式——查到了就改。

### 直接说正确的

不要先给读者立一个他没有的误解再推翻。读者不需要被冤枉。

自查：有没有以下句式？
- "不是……而是……"
- "很多人以为……其实……"
- "表面上……实际上……"
- "看起来……但……"
- "与其说……不如说……"
- "真正重要的是……"
- "说到底……"

### 两件事并列，不排三件

两项并列可以，三项及以上排比——拆。

自查：有没有这些结构？
- "第一……第二……第三……"
- "一方面……另一方面……与此同时……"
- "既要……又要……还要……"

### 用日常词，不用模型腔

自查：有没有这些词？
- "说白了" / "说穿了" / "说到底是" / "本质上"
- "意味着什么" / "意味着"
- "不可否认" / "毫无疑问" / "众所周知"
- "更微妙的是" / "还有一层" / "更深一层"
- "关键在于" / "核心在于" / "重点在于"
- "总的来说" / "总而言之" / "综上所述"
- "基于" / "赋能" / "抓手" / "闭环" / "底层逻辑"
- "不过……" / "然而……" / "尽管如此……"（每段开头用转折词）

### 句号断句，不喊口号

自查：
- 有没有破折号（——）？改成句号
- 有没有提示性冒号（"答案很简单："、"核心逻辑是："）？删掉冒号，直接说
- 有没有感叹号？改成句号
- 有没有"这，就是……的力量"、"而这，仅仅是开始"、"让我们一起……"、"你会发现一个全新的世界"？删

## 教学文本特别规则

### 结论先行

每节第一句说结论，然后展开。不要铺垫三段才到重点。

### 具体举例

举例子用真实工具名、真实命令、真实场景。不写"比如某个工具"、"假设有一个系统"。

### 事实先行，判断在后

先说事实，再给判断。不要反过来——读者先看到判断会警惕。

对：`npm install` 会读取 package.json，把依赖装到 node_modules。如果 package.json 不存在，它会报 ENOENT。
错：安装依赖时一定要有 package.json，否则会报错。因为 npm install 会读取 package.json……

### 读者直呼

用"你"直接对读者说话。不用"我们"、"大家"、"学习者"、"读者朋友们"。

### 短段落

一段说一件事。中文段落 3–5 行是舒适的阅读密度。超过 8 行就拆。

### 留白

不用每段都总结。不用每节结尾加一句"这就是……"。说完就停。

---

## 自检清单

写完正文后，逐条检查：

1. 有没有翻案腔？"不是……而是……"、"很多人以为……"——有就删
2. 有没有三项以上排比？——有就拆
3. 有没有 AI 高频词？"说白了"、"意味着"、"本质上"——有就删
4. 有没有破折号？——有就改成句号
5. 有没有空洞感叹？——有就删
6. 每段开头有没有转折词？"不过"、"然而"——有就删
7. 每段有没有带来新东西？删掉这段会少知道什么？——没少就删
8. 举例有没有用真实名字？——假名就换成真的
9. 有没有先判断后事实的段落？——有就反过来
10. 有没有"接下来""下面我们""让我们"这类引导语？——有就删，直接开始说
