# RESOURCES.md Format

`RESOURCES.md` is the curated set of trusted sources for this topic. Knowledge for explainers should be drawn from here, not from parametric guesses.

## Structure

```md
# {Topic} Resources

## Knowledge

- [Book: _Title_ — Author](https://example.com)
  One-line summary of what it covers and when to reach for it.
- [Article: "Title" — Author (Source)](https://example.com)
  One-line summary of what it covers and when to reach for it.

## Gaps
- {Area the mission needs but no good resource exists for yet}
```

## Rules

- **High-trust only.** Prefer primary sources, recognised experts, peer-reviewed work. If a resource is marketing dressed as education, leave it out.
- **Annotate every entry.** A bare link is useless in three months. Add one line: what it covers and when to reach for it.
- **Surface gaps explicitly.** If no good resource exists for an area the mission needs, write a `## Gaps` section listing what is missing. This drives future search.
- **Prune ruthlessly.** A resource that turned out to be wrong, shallow, or off-mission should be removed, not buried. Better five sharp sources than thirty mediocre ones.
